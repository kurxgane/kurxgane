## Projetos em destaque

### 🎬 CineTracker

Aplicação desktop desenvolvida em Python para organizar uma biblioteca pessoal de filmes. Utiliza a API OMDb para pesquisar títulos e permite acompanhar o que o usuário pretende assistir, registrar avaliações e visualizar estatísticas sobre seus hábitos cinematográficos.

**Tecnologias:** Python, CustomTkinter, OMDb API, Requests, Pillow, Matplotlib e JSON.

- 💻 [Ver repositório](https://github.com/kurxgane/CineTracker)

### 🌱 Mapa de Aptidão Agrícola

Aplicação web que permite analisar a aptidão climática de diferentes culturas agrícolas em pontos do estado de São Paulo.

Utiliza dados climáticos da NASA POWER para classificar a aptidão como Apta, Moderada ou Inapta, apresentando fatores limitantes e informações visuais para auxiliar na análise.

**Tecnologias:** JavaScript, Leaflet, Chart.js e NASA POWER.

- 🌐 [Acessar aplicação](https://mapadeaptidao.netlify.app)
- 💻 [Ver repositório](https://github.com/kurxgane/mapadeaptidao)
